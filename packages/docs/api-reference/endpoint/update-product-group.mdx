title: 'Update a product group'
description: 'Omitted fields stay unchanged. `products`, when sent, is the complete ordered member list: products it does not contain are removed, and its order is the display order. The request is compared with the stored group first: a request that changes nothing answers `write_result.result` `unchanged` and writes nothing, and an equal ordered member list writes no member. The product group comes back with `write_result`.'
openapi: patch /v1/product-groups/{id}
