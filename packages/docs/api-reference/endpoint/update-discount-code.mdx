---
title: 'Update a discount'
description: 'Update a discount. Only supplied fields change; the code never does. Once redeemed, its amount, type, currency and duration are fixed. A discount with a Stripe coupon also keeps its expiry, redemption limit and products; a name change renames the coupon. A request that changes nothing answers `unchanged` and writes nothing. The discount comes back with `write_result`.'
openapi: patch /v1/discounts/{id}
---
