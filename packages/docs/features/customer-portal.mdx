## What is the Customer Portal?

The Customer Portal is where your customers look after what they bought from you: their subscriptions, the card they pay with, their invoices, and their files and license keys. They do it themselves, so fewer of these requests reach your support.

Each store has its own portal. It shows your logo and brand colour from **Settings › Branding**.

## How customers get in

- **From their emails.** Every payment confirmation email has a link that opens the portal with no password. The link works for a few days and can be opened more than once.
- **From the sign-in page.** At any time, a customer can enter their email at [creem.io/my-orders/login](https://creem.io/my-orders/login) to get a new sign-in link, or sign in with Google.

A customer sees only the purchases made with their own email address.

## What can customers do in the Customer Portal?

### 1. Manage a subscription

Customers see each subscription with its plan, price, status and next payment date. From there they can:

- **Cancel it.** They review what happens before they confirm. They aren't charged again, and their access ends right away or at the end of the billing period, depending on your store's setting.
- **Resume it**, while a cancelled subscription is still running.
- **Change plan**, between products in a [product bundle](/features/product-bundles) that has self-service upgrades turned on.

### 2. Update their card

Customers can replace the card a subscription renews with. When a renewal fails, they can pay it with a new card, and the subscription becomes active again.

### 3. Download invoices

Every payment is listed with its invoice. When downloading one, the customer can add a company name and address to it.

### 4. Get their files and license keys

Customers can download the files and copy the license keys that came with a purchase.

### What customers can't do

- **Pause a subscription.** They can cancel, and resume before the billing period ends.
- **Keep several payment methods.** Each subscription has one card on file. It can be replaced, not removed.
- **Change their email.** They ask you, and you change it for them.
- **Get a refund.** Refunds are your decision, so the portal tells them to contact you.

The portal's Help section answers these questions and shows your store's support contact.

## Generate Customer Portal Access Programmatically

You can generate a customer portal link for your users programmatically, allowing them to manage their subscriptions directly from your application.

<Tabs>
  <Tab title="Next.js">

**Step 1: Create the Portal Route**

```typescript
// app/portal/route.ts
import { Portal } from "@creem_io/nextjs";

export const GET = Portal({
  apiKey: process.env.CREEM_API_KEY!,
  testMode: process.env.NODE_ENV !== "production",
});
```

**Step 2: Use the Component**

```tsx
// components/ManageSubscriptionButton.tsx
"use client";

import { CreemPortal } from "@creem_io/nextjs";

export function ManageSubscriptionButton({ customerId }: { customerId: string }) {
  return (
    <CreemPortal customerId={customerId}>
      <button className="btn-primary">Manage Subscription</button>
    </CreemPortal>
  );
}
```

```typescript
import { Creem } from "creem";

const creem = new Creem({
  apiKey: process.env.CREEM_API_KEY!,
  server: process.env.NODE_ENV === "production" ? "prod" : "test",
});

// Create customer portal link
const portal = await creem.customers.generateBillingLinks({
  customerId: "cust_abc123",
});

// Redirect user to portal
console.log(portal.customerPortalLink);
// Output: https://creem.io/my-orders/login/xxxxxxxxxx
```

You can also retrieve the customer ID by email:

```typescript
// Get customer by email first
const customer = await creem.customers.retrieve(undefined, "customer@example.com");

// Then create portal link
const portal = await creem.customers.generateBillingLinks({
  customerId: customer.id,
});

// Redirect to portal
window.location.href = portal.customerPortalLink;
```

**Client-Side Usage:**

```typescript
"use client";

import { authClient } from "@/lib/auth-client";

export function ManageSubscriptionButton() {
  const handlePortal = async () => {
    const { data, error } = await authClient.creem.createPortal();

    if (data?.url) {
      window.location.href = data.url;
    }

    if (error) {
      console.error("Failed to create portal:", error);
    }
  };

  return (
    <button onClick={handlePortal}>
      Manage Subscription
    </button>
  );
}
```

```json
{

```

### JavaScript Example

```javascript
const response = await fetch("https://api.creem.io/v1/customers/billing", {
  method: "POST",
  headers: {
    "x-api-key": "YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    customer_id: "cust_abc123",
  }),
});

const data = await response.json();
console.log(data.customer_portal_link);
```

## Limitations

Customers can only switch plans in the Customer Portal between products in a [product bundle](/features/product-bundles) that has self-service upgrades turned on. Outside of bundles, customers can't move to another product, and they can't change only their billing cycle.

To handle plan changes in your own application instead, use the [subscription upgrade API](/features/subscriptions/managing#programmatic-upgrades).

<Note>
  Editing a product's price doesn't change what existing subscribers pay. See [Changing a Product's
  Price](/features/subscriptions/managing#changing-a-products-price) for how to move them to a new
  price.
</Note>
