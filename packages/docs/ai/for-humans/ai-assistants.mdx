title: Use Creem in Your AI Assistant
description: Connect Claude Code, Codex, Claude, ChatGPT or Cursor to your Creem store and manage products, checkout links, customers and subscriptions by chatting. No API key.
---

Connect Claude Code, Codex, Claude, ChatGPT or Cursor to your Creem store, and you can ask about sales, find a customer, create a checkout link or cancel a subscription in a normal chat. You sign in with your Creem account, so there is no API key to copy.

## What you can ask

Once Creem is connected, ask in your own words. For example:

- "How much revenue did I make in the last 30 days?"
- "List my products and create a checkout link for the Pro plan."
- "Find the customer jane@example.com and show me her subscription."
- "Create a 20% discount code called LAUNCH20."
- "Cancel the subscription for jane@example.com."
- "What do I still need to fill in before I can take live payments?"

Your assistant can work with products, checkout links, discount codes, customers, subscriptions, transactions, disputes, revenue and your business details. In live mode it can fill in your business details for you, but you submit them yourself in the dashboard. It can't move money: there are no tools for refunds or payouts, so you make those in the [dashboard](https://creem.io/dashboard).

## Connect Claude Code

<Tip>
  Already connected Creem in Claude? Claude Code signed in with the same Claude account picks up
  your Claude connectors, so Creem is already there. Type `/mcp` in Claude Code to check.
</Tip>

<Steps>
  <Step title="Add Creem">
    In your terminal, run:

    ```bash
    claude mcp add --transport http --scope user creem https://mcp.creem.io/mcp
    ```

    `--scope user` makes Creem available in every project.

  </Step>
  <Step title="Sign in">
    Start Claude Code, type `/mcp`, select **creem** and choose **Authenticate**. Your browser opens
    the Creem sign-in, as described in [Sign in and choose what it can do](#sign-in-and-choose-what-it-can-do).
  </Step>
  <Step title="Ask">Ask Claude Code a question about your store.</Step>
</Steps>

## Connect Codex

Codex 0.147 or newer works. The Codex CLI, the Codex IDE extension and the ChatGPT desktop app share one setup, so adding Creem once makes it available in all three.

<Steps>
  <Step title="Add Creem">
    In your terminal, run:

    ```bash
    codex mcp add creem --url https://mcp.creem.io/mcp
    ```

  </Step>
  <Step title="Sign in">
    Run `codex mcp login creem`. Your browser opens the Creem sign-in, as described in [Sign in and
    choose what it can do](#sign-in-and-choose-what-it-can-do).
  </Step>
  <Step title="Ask">Start Codex and ask a question about your store.</Step>
</Steps>

## Connect Claude

Add Creem on claude.ai or in Claude Desktop. Once it's connected, it works in the Claude mobile apps too.

<Steps>
  <Step title="Add Creem">
    In Claude, open **Customize → Connectors** and select **Add custom connector**. Enter `Creem` as
    the name and `https://mcp.creem.io/mcp` as the URL, then select **Add**. If Claude shows sign-in
    settings first, keep the ones it detected and continue.
  </Step>
  <Step title="Connect">
    Select **Connect**. Your browser opens the Creem sign-in. Sign in and allow access, as described
    in [Sign in and choose what it can do](#sign-in-and-choose-what-it-can-do).
  </Step>
  <Step title="Ask">Start a new chat and ask a question about your store.</Step>
</Steps>

On Team and Enterprise plans, an Owner of your Claude organization adds the connector first, in **Organization settings → Connectors**. Each member then finds Creem under **Customize → Connectors**, selects **Connect** and signs in with their own Creem account.

## Connect ChatGPT

Custom connections work in ChatGPT on the web, and your plan or workspace has to allow them. See OpenAI's [Connecting custom MCP servers in ChatGPT](https://help.openai.com/en/articles/12584461-developer-mode-apps-and-full-mcp-connectors-in-chatgpt).

<Steps>
  <Step title="Add Creem">
    Go to [ChatGPT Plugins](https://chatgpt.com/plugins), select the plus button, then **Add custom
    MCP server**. Name it `Creem` and enter `https://mcp.creem.io/mcp` under **Connection**.
  </Step>
  <Step title="Choose OAuth">
    Choose **OAuth** and leave the client ID and secret empty. Review the risk warning, tick **I
    understand and want to continue**, then select **Create as a plugin**.
  </Step>
  <Step title="Sign in">
    Install the plugin and sign in with your Creem account when ChatGPT asks.
  </Step>
</Steps>

## Connect Cursor

<Steps>
  <Step title="Add Creem">
    Open `~/.cursor/mcp.json`, or create it, and add Creem:

    ```json
    {
      "mcpServers": {
        "creem": {
          "url": "https://mcp.creem.io/mcp"
        }
      }
    }
    ```

    If the file already lists other servers, add the `creem` entry next to them.

  </Step>
  <Step title="Sign in">
    Open **Customize** in Cursor's sidebar, connect **creem** and sign in with your Creem account.
    The sign-in page shows Cursor as **Not verified by Creem**. That is expected for apps that
    register themselves when they connect.
  </Step>
  <Step title="Ask">Ask Cursor's agent a question about your store.</Step>
</Steps>

Cursor's cloud agents can't connect: sign-in only completes in Cursor on your own computer.

## Sign in and choose what it can do

When you connect, Creem's sign-in page opens. Sign in with the account you use for the Creem dashboard. Then choose:

- **Store:** the store the assistant works in. One connection works on one store.
- **Start in:** **Test mode** uses your test data, with no real payments or customers. **Live mode** works on your real store. Live mode is preselected, so pick **Test mode** if you want to try things out first.
- **Permissions:** every permission the assistant asks for starts ticked. Untick what you don't want it to do:

| Permission                                        | What it allows                                                                                                                          |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **View your store**                               | See products, customers, subscriptions, transactions, disputes, revenue and your business details                                       |
| **Manage products, checkout links and discounts** | Create, edit and archive products, create checkout links, and create and delete discount codes                                          |
| **Fill in and submit your business details**      | Save your business details as a draft and submit them to Creem for review. Today's tools only save a draft: you submit in the dashboard |
| **Manage subscriptions**                          | Change, upgrade, pause, resume or cancel your customers' subscriptions. Today's tools can only cancel                                   |

- **Ask before risky actions:** ticked by default. Leave it ticked so the assistant asks you before cancelling a subscription, creating or deleting a discount code, changing a product's price, currency, trial or success URL, or archiving a product.

Select **Allow** to finish. You, and the store owner if that's someone else, get an email when an assistant is connected.

## Stay in control

- **You confirm risky actions.** With **Ask before risky actions** on, Creem asks you, not the assistant, before anything that can't be undone. Switching to live mode always asks.
- **Try it in test mode.** In test mode nothing touches real payments or customers, so mistakes don't matter.
- **Grant only what you need.** An assistant that only answers questions about your sales needs **View your store** and nothing else.
- **Every answer shows the mode.** Results and confirmations say whether they ran in test or live mode.

## Change mode or disconnect

In the [dashboard](https://creem.io/dashboard), go to **Settings → Connected apps**. There you can switch a connection between test and live mode, turn **Ask before risky actions** on or off, or disconnect it. You can also ask your assistant to "switch Creem to live mode".

When you disconnect, the assistant stops working with your store within a minute. Anything it already changed, such as a new product or a cancelled subscription, stays.

## Other apps

Any other app that connects to remote MCP servers can use Creem: add `https://mcp.creem.io/mcp` and sign in. Sign-in has to finish on your own computer, so apps that run only in the browser, apart from Claude and ChatGPT, can't connect yet. The [Hosted MCP Server](/ai/for-agents/hosted-mcp#other-clients) page has the setup, the full tool list and troubleshooting.
