Use Creem's remote Model Context Protocol (MCP) server to give AI agents access to your Creem store. Agents can look up data and take actions across your products, checkout links, discount codes, customers, subscriptions, transactions and disputes.

<Note>
  Creem MCP uses OAuth. When you connect a client, your browser opens so you can sign in with your
  Creem account and authorize access to your store. You never need to copy an API key into your
  agent.
</Note>

## Connect your agent

Use the server at `https://mcp.creem.io/mcp`. The same URL serves test and live mode: you choose the mode when you authorize (see [Test and live mode](#test-and-live-mode)).

Choose your client and add the server.

<Tabs>
  <Tab title="Claude Code">
    Run:

    ```bash
    claude mcp add --transport http creem https://mcp.creem.io/mcp
    ```

    Then open `/mcp` in Claude Code and authenticate `creem`. Add `--scope user` to make Creem available in every project.

  </Tab>
  <Tab title="ChatGPT">
    Open [ChatGPT Plugins](https://chatgpt.com/plugins), select the plus button, then **Add custom MCP server**, and enter:

    - **Name:** `Creem`
    - **Connection:** `https://mcp.creem.io/mcp`
    - **Authentication:** OAuth, with the client ID and secret left empty

    Select **Create as a plugin**, install it, and complete authorization in the browser. Your ChatGPT plan or workspace has to allow custom MCP servers ([OpenAI help](https://help.openai.com/en/articles/12584461-developer-mode-apps-and-full-mcp-connectors-in-chatgpt)).

  </Tab>
  <Tab title="Codex">
    Run:

    ```bash
    codex mcp add creem --url https://mcp.creem.io/mcp
    codex mcp login creem
    ```

    Complete the authorization in the browser. Requires Codex 0.147 or newer. The CLI, the IDE extension and the ChatGPT desktop app share this configuration.

  </Tab>
  <Tab title="Other clients">
    Claude.ai, Claude Desktop, Cursor, VS Code and other clients can't authorize with Creem MCP yet:
    sign-in fails with `invalid_client`.

    Use the [local MCP server](/ai/for-agents/mcp-server) instead. It runs on your machine with an API key and works with any client that can start a local command.

  </Tab>
</Tabs>

## Test and live mode

A connection works in one mode at a time. **Test mode** uses your store's [test data](/getting-started/test-mode), and no real money moves. **Live mode** works on real payments, refunds and subscriptions.

You choose the mode when you authorize. Live is preselected when your store is approved for live payments. To change it later, ask your agent (for example "switch Creem to live mode") or use **Settings → Connected apps** in the dashboard. Switching to live asks you to confirm. Every tool result states the mode it ran in.

## Permissions

When you authorize, you pick a store and choose what the agent can do in it:

| Permission                                        | Allows                                                                                               |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **View your store**                               | Reading products, checkouts, discounts, customers, transactions, subscriptions, disputes and revenue |
| **Manage products, checkout links and discounts** | Creating, editing and archiving products, creating checkout links, creating and deleting discounts   |
| **Manage subscriptions**                          | Cancelling subscriptions                                                                             |
| **Issue refunds**                                 | Refunding payments                                                                                   |

For an agent that should look up data but never change it, leave only **View your store** ticked. A tool outside the granted permissions fails with `missing scope`. To add a permission later, connect again: authorization keeps what you already allowed and offers the rest.

## How the tools work

The server gives your agent a curated set of tools, each for one task, such as `list_subscriptions`, `create_checkout_link` or `issue_refund`. Every tool is marked read-only or not, so your client knows which calls change data. See [Available tools](#available-tools) for the full list, and [Permissions](#permissions) for what each needs.

Before a refund, a cancellation, a delete, an archive, a new discount, a price change or a switch to live, Creem asks **you** to confirm. Clients that can show a prompt display it with **Accept** and **Decline**. In other clients, the agent shows you the question in the chat and continues only after you answer "yes". A confirmation covers that exact action, works once and expires after 10 minutes.

## Manage connections

**Settings → Connected apps** in the dashboard lists the agents connected to your store, who connected them and their mode. Switch a connection's mode or disconnect it there. You can manage the connections you made; the store owner can manage all of them.

A disconnected agent has to authorize again. Changes it already made, such as refunds or new products, stay. You and the store owner get an email when an agent is connected or gets new permissions.

## Limits

Each connection can make 120 calls and 30 writes per minute. Each store can make 300 calls and 60 writes per minute across its connections, counted separately for test and live mode. A call over a limit fails with `rate_limited` and changes nothing.

## Available tools

<Accordion title="Available tools (24)">

| Tool                         | Description                                                                                                                                          |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `list_products`              | List products with price, billing type, status and payment links.                                                                                    |
| `get_product`                | Get a product.                                                                                                                                       |
| `get_revenue_summary`        | Get revenue, payments, new customers and subscriptions for a date range, and MRR.                                                                    |
| `search_customers`           | Find a customer by email, or list customers.                                                                                                         |
| `get_customer`               | Get a customer with their newest subscriptions and orders.                                                                                           |
| `list_subscriptions`         | List subscriptions with status, product, customer and payment dates.                                                                                 |
| `get_subscription`           | Get a subscription and its last transaction.                                                                                                         |
| `list_transactions`          | List payments and subscription invoices with tax, discount and refunded amounts.                                                                     |
| `get_checkout`               | Get a checkout session and, once paid, its order.                                                                                                    |
| `list_discounts`             | List discount codes with their redemptions.                                                                                                          |
| `get_discount`               | Get a discount by ID or code.                                                                                                                        |
| `list_disputes`              | List disputes and the date to send evidence by.                                                                                                      |
| `get_dispute`                | Get a dispute.                                                                                                                                       |
| `open_business_details`      | Get a dashboard link to the business details form, the first step to live payments.                                                                  |
| `open_identity_verification` | Get a dashboard link to identity verification.                                                                                                       |
| `create_product`             | Create a product.                                                                                                                                    |
| `create_checkout_link`       | Create a checkout link for a product.                                                                                                                |
| `create_discount`            | Create a discount code. **Asks to confirm.**                                                                                                         |
| `update_product`             | Update a product. Price, currency and trial changes apply to new purchases only. **Asks to confirm a price, currency, trial or success URL change.** |
| `archive_product`            | Archive a product. Existing subscriptions keep renewing. **Asks to confirm.**                                                                        |
| `delete_discount`            | Delete a discount code. **Asks to confirm.**                                                                                                         |
| `cancel_subscription`        | Cancel a subscription. **Asks to confirm.**                                                                                                          |
| `issue_refund`               | Refund a payment. **Asks to confirm.**                                                                                                               |
| `switch_mode`                | Switch the connection between test and live mode. **Asks to confirm a switch to live.**                                                              |

</Accordion>
