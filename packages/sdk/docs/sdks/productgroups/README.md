# ProductGroups

## create

Link products a customer can switch between. A product belongs to one group at a time: one in another group answers `409` with code `product_already_grouped`. An unknown product answers `400` with code `reference_not_found`. With an `external_id` the call is an upsert: it creates the group when the key is new (`201`) and updates the group that holds the key otherwise (`200`). Only the fields you send change, each with the meaning `PATCH /v1/product-groups/{id}` gives it; `products`, when sent, is the complete ordered member list. The request is compared with the stored group first, so a request that changes nothing answers `unchanged` and writes nothing, and retrying after a timeout is safe. The product group comes back with `write_result`. Send `If-None-Match: *` to create only.

## update

Omitted fields stay unchanged. `products`, when sent, is the complete ordered member list: products it does not contain are removed, and its order is the display order. The request is compared with the stored group first: a request that changes nothing answers `write_result.result` `unchanged` and writes nothing, and an equal ordered member list writes no member. The product group comes back with `write_result`.

      externalId: "pro-plans",

## addProduct

Add one product, by its `id` or its `external_id` (exactly one of the two), at the end of the group. A product already in this group answers `200` with the group unchanged; one in another group answers `409` with code `product_already_grouped`; an unknown one answers `400` with code `reference_not_found`.
