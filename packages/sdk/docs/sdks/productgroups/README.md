# ProductGroups

## Overview

### Available Operations

* [list](#list) - List product groups
* [get](#get) - Retrieve a product group

## list

List your product groups, newest first, as a cursor page. Filter by your own `external_id`.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="listProductGroups" method="get" path="/v1/product-groups" -->
```typescript
import { Creem } from "creem";

const creem = new Creem({
  apiKey: process.env["CREEM_API_KEY"] ?? "",
});

async function run() {
  const result = await creem.productGroups.list({
    externalId: "plans",
  });

  for await (const page of result) {
    console.log(page);
  }
}

run();
```
