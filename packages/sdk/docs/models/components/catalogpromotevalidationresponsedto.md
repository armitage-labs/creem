# CatalogPromoteValidationResponseDto

On the real run’s first page: how its writes were checked before the first one. Null otherwise.

## Example Usage

```typescript
import { CatalogPromoteValidationResponseDto } from "creem/models/components";

let value: CatalogPromoteValidationResponseDto = {
  scope: "<value>",
  batches: 69651,
  checkedBatches: 345991,
  passed: true,
  written: true,
};
```
