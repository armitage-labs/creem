            | ID of the Moderation API result (`id` from `POST /v1/moderation/prompt`) that authorizes this spend. Optional, and only allowed on a transaction that debits a customer account; validated and linked whenever sent. A transaction cannot debit a `generation` account (AI generation credits): spend those with `POST /v1/customer-credits/accounts/{id}/debit`. The result must belong to this store, have decision `allow`, be inside its 24-hour window (at most 24 hours old and not dated in the future) and not already be linked to another transaction: each id can be used once. To debit again for the same prompt, screen it again and send the new id.
